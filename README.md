📊 Sales Performance Analysis Dashboard

🚀 Project Overview

This project focuses on analyzing sales data to uncover insights related to revenue, profitability, and customer behavior. It demonstrates an end-to-end data analysis workflow including data cleaning, database management, SQL analysis, and dashboard visualization.


🎯 Objective

* Analyze sales performance across different dimensions
* Identify trends and patterns in revenue and profit
* Understand customer behavior and repeat purchases
* Evaluate the impact of discounts on profitability



🛠️ Tools & Technologies

* **Python** – Data cleaning and preprocessing
* **PostgreSQL** – Data storage and SQL analysis
* **Power BI** – Data visualization and dashboard

 🔄 Project Workflow

1. **Data Cleaning (Python)**

   * Handled missing values
   * Removed duplicates
   * Converted data types
   * Created new features (Year, Month, Profit Margin)

2. **Data Storage (PostgreSQL)**

   * Created database and tables
   * Loaded cleaned data using SQLAlchemy
   * Performed structured data storage

3. **SQL Analysis**

   * Total Sales and Profit calculation
   * Sales trends over time
   * Sales by category and region
   * Top-performing products
   * Repeat customer analysis
   * Discount vs Profit analysis

4. **Dashboard (Power BI)**

   * KPI cards (Sales, Profit, Profit Margin)
   * Sales trend visualization
   * Category and regional analysis
   * Top products
   * Customer insights
   * Interactive filters



📊 Dashboard Features

* 📈 Sales Trend Analysis
* 📊 Category-wise Sales
* 🌍 Region-wise Profit
* 🏆 Top 10 Products
* 🔁 Repeat vs One-time Customers
* 📉 Discount Impact on Profit

🔍 Key Insights

* Sales peak during November and December
* Technology category generates the highest revenue
* High discounts negatively impact profitability
* Repeat customers contribute significantly to total sales
* Some products generate high sales but low profit

This project demonstrates how data analysis can be used to derive meaningful business insights. It highlights the importance of structured data processing, SQL-based analysis, and effective visualization.
